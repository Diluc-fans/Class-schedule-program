# Schedule Pro v4.7 — Програма для розкладу занять

Цей проєкт є курсовою роботою з розробки програмної системи для моделювання та управління розкладом занять. Застосунок реалізовано на мові Java з використанням графічної бібліотеки Java Swing.

## 🚀 Основні можливості програми
* **Інтерактивний інтерфейс:** Використання багатошарових панелей `JLayeredPane` та кастомного графічного менеджера `CardLayout`.
* **Анімаційні ефекти:** Плавне висувне бічне меню навігації (Side Drawer).
* **Управління даними:** Локальне збереження та зчитування розкладу у форматі JSON (`data.json`).
* **Кастомізація профілю:** Можливість редагування особистих даних користувача (ПІП, курс, спеціальність) та завантаження аватара.

## 📊 Реалізовані алгоритми та структури даних
1. **Матрична структура:** Дані розкладу структуровані у вигляді матриці `Matrix[11][5]`, яка містить динамічні списки об'єктів `ArrayList<Lesson>`.
2. **Прямий пошук рядка (Brute Force):** Пошук занять в системі за текстовим збігом у назві предмета.
3. **Пошук за ключем:** Швидка фільтрація та вибірка занять за номером аудиторії.
4. **Емпіричний аналіз швидкодії:** Вбудований бенчмарк для ітераційного обходу структури даних з оцінкою теоретичної часової складності $O(n)$.
